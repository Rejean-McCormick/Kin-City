# Kin City — motifs de pancartes sans logo (source)

Ces SVG et PNG sont inclus pour versionner le design et fournir une référence aux artistes.
**Ils ne sont PAS chargés par Roblox depuis le système de fichiers.** Le moteur SignEngine v31.8
reproduit en GUI Roblox (Frames, UIStroke) leurs filets, cadres, équerres et séparateur de logo.

Le logo officiel n'est pas inclus, dessiné ni remplacé. Un emplacement n'est réservé à gauche
que sur les enseignes principales. Aucun Asset ID Roblox requis.

Les quatre motifs : `kin_sign_frame_9slice`, `kin_sign_corner_bracket`,
`kin_sign_divider_rule`, `kin_sign_logo_separator`.
