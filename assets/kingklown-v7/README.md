# Chevelure sculptée King Klown v7

Géométrie originale générée par `tools/generate_v28_meshes.py` : sept mèches effilées et courbes sur une calotte, sans couronne. OBJ fermé par composante, triangles, coordonnées normalisées. Le script de costume applique les dimensions et le centrage de `geometry.json`.

Importer `kingklown-hair-v7.obj` dans Studio, sélectionner le MeshPart puis exécuter `KingKlown_Enregistrer_Cheveux_v7.luau` à la racine du dépôt. Importer sans rotation ni miroir. Répéter dans chaque Place qui doit utiliser ce modèle. Aucun AssetId n'est fourni.

Sans import, le costume utilise des mèches courbes en primitives natives. Le modèle OBJ n'a pas été importé ni observé dans Roblox au moment de la livraison.
