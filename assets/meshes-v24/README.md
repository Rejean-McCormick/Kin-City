# Trois pièces architecturales originales — Kin City v24

OBJ centrés, normalisés et conçus pour la mise à l'échelle via `MeshPart.Size`.
- `crystal-canopy.obj` : couronnement octogonal facetté
- `mineral-planter.obj` : bac minéral ouvert
- `opal-console.obj` : pupitre opalin incliné

Exporter/importer ces OBJ via **Roblox Studio > Import**, puis enregistrer leur MeshPart dans `ServerStorage.KinCityAssetLibrary` avec `KinCity_Enregistrer_Mesh_Studio_v24.luau`. Aucun identifiant n'est fourni ou inventé.
Sans import, le code crée une sculpture équivalente à partir de primitives natives.
