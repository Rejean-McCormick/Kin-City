# Kit de cinq meshes de Kin City v23

Fichiers OBJ + matériau MTL produits localement, originaux, sans asset tiers. Unités normalisées; Roblox fixe la taille par code. Importer les OBJ dans Roblox Studio/Creator Hub, obtenir les IDs utilisables avec SpecialMesh, puis remplir `config/meshes.json` et régénérer l'installateur. Les champs `null` déclenchent des volumes natifs Roblox : l'installateur reste autonome sans import. Les meshes ne contiennent ni rig, ni collision; ils sont uniquement décoratifs.

- `mineral-column.obj` : pilier cannelé et facetté
- `opal-spire.obj` : pointe de cristal
- `crystal-rosette.obj` : relief radial
- `opal-arch.obj` : arche minérale
- `opal-chandelier.obj` : luminaire facetté
