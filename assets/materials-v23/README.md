# Matériaux v23 — textures originales et périodiques

Quatre ensembles de maps 512 × 512 créés par algorithme local, sans assets tiers. Chaque matériau comprend `color`, `normal` et `roughness`. La planche `palette-apercu.png` montre uniquement les textures générées, pas un résultat dans Roblox.

Importation **optionnelle** dans Roblox Studio > Material Manager / MaterialVariant. Réutiliser sur les structures, ne pas produire une variante par instance. Les générateurs Kin City livrés restent fonctionnels avec les matériaux natifs; l'import PBR n'est pas automatisé faute d'AssetIds publiés.
