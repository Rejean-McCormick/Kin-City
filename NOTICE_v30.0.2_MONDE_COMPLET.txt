KIN CITY v30.0.2 — CORRECTIF DU MONDE ABSENT
=============================================

CAUSE CONFIRMEE PAR LE JOURNAL ROBLOX STUDIO
Le script v30.0.1 construit la ville (22 020 objets) et trois institutions,
puis échoue sur :
    ServerScriptService.KinCityRuntime.PropGenerator:57:
    Unknown asset generator: prop.desk
Ce mobilier canonique appartient au laboratoire d'innovation. Le secours
v27 réutilisait PropGenerator et échouait donc sur la même erreur.

CORRECTIF v30.0.2
- Une vraie géométrie est maintenant générée pour prop.desk.
- L'identifiant du meuble, son ancre hall.desk_01 et l'interaction sont conservés.
- Un contrôle préalable vérifie que tous les types de mobilier du plan actif
  disposent d'un générateur avant que KinCityGenerated soit reconstruit.
- Le script complet réinstalle ville + huit institutions dans une seule Place.
- Les installateurs des neuf Places et le local standard sont régénérés.

INSTALLATION — UNIVERS COMPLET
1. Ouvrir Roblox Studio sur une copie du projet, en mode EDITION, Play arrêté.
2. Ouvrir Affichage / Command Bar (barre de commande).
3. Copier TOUT le fichier KinCity_Installation_Univers_Complet_v30.0.2.luau
   dans la barre de commande puis cliquer Exécuter une fois.
4. Lire la fenêtre Sortie (Output) : chaque institution est annoncée, puis
      KIN CITY : MONDE PRÊT — ville + 8 institutions
      KIN CITY : SUCCES - la ville et les 8 institutions existent
5. Dans Explorer, vérifier Workspace > KinCityGenerated > Ville et
   Workspace > KinCityGenerated > Bâtiments visitables.
6. Sauvegarder la Place. Démarrer Play pour essayer les portes locales.

IMPORTANT
- Ne pas utiliser l'ancienne v30.0.1 : cette version ne connaît pas prop.desk.
- Le script v30.0.2 peut détruire/reconstruire KinCityGenerated ; toute retouche
  manuelle dans ce dossier sera remplacée.
- Aucun PlaceId ni AssetId inventé, aucune transmission de données.
- Le message Studio « command exceeds the size limit ... saved commands » signifie
  uniquement que la commande n'est pas enregistrée dans l'historique.
- Les intérieurs sont éloignés dans la même Place et les portes utilisent le
  parcours local, sans véritables téléportations inter-Places publiées.

VERIFICATIONS EFFECTUEES HORS STUDIO
- 101 tests Python ont réussi ; 3 modules n'ont pu démarrer faute de lupa.
- Les 11 types de mobilier des neuf lieux figurent dans le registre de
  PropGenerator et disposent tous d'une branche géométrique.
- L'installateur compact est reconstruit à partir des sources modifiées.
- Aucun test moteur Studio n'a pu être effectué dans cet environnement.

Si la prochaine installation échoue, transmettre les lignes de Sortie depuis
« KIN CITY : debut installation » jusqu'à la PREMIERE erreur rouge.
