KIN CITY — VERSION 21 (19 OCTOBRE 2026)

1. Ouvrir une COPIE du projet Roblox Studio en mode Édition.
2. Ouvrir KinCity_Installation_Directe_v21.luau et tout copier.
3. Dans Studio : View > Command Bar, coller, puis exécuter.
4. Laisser le script terminer la génération de la ville dans l'éditeur ; lancer Play.
5. Explorer le centre et les quartiers résidentiels : les habitants R15 s'animent près du joueur.
6. E : interaction ; M : carte ; N : destinations ; J : carnet ; G : correspondances.

AUDIO : désactivé par défaut. Pour l'activer, importer les trois sons WAV
assets/audio/*.wav dans Creator Hub, configurer les IDs dans config/audio.json,
puis régénérer l'installateur avec python tools/build_release.py.

Attention : cette version écrase directement les anciens dossiers Kin City gérés
par l'installateur. Aucun retour arrière automatique. Le rendu Roblox Studio et
les performances mobile n'ont pas été certifiés depuis cet environnement.
Aucune connexion à kOA ou IA payante active.
