# Publish the Kin City Wiki on GitHub

This directory contains **ready-to-publish GitHub Wiki pages**. The package was generated from the Kin City **v26** source and installation guides. The GitHub-hosted Wiki has **not been edited automatically**.

## Option 1 — GitHub web interface

1. Open your Kin City GitHub repository → **Settings** → enable **Wikis** (when available for your account/repository).
2. Open the **Wiki** tab and create a first page named `Home` if prompted.
3. Use **New Page** to add content from each `.md` file, keeping the exact basename as the page name (for example, `Quick-Start.md` → `Quick-Start`).
4. In **Edit custom sidebar**, paste `_Sidebar.md`; in the custom footer, paste `_Footer.md` if your GitHub Wiki UI supports it.
5. Upload the optional image `images/kin-city-material-palette.png` by cloning the Wiki repository (Option 2), or remove the image lines from Home/Art if publishing only through the browser.

## Option 2 — Git (recommended for the full package)

A GitHub Wiki is a **separate Git repository**; merely uploading these files into your main source repository under `docs/` does **not** publish them as Wiki pages.

First create the Wiki through GitHub's browser interface so the `<owner>/<repo>.wiki.git` remote exists. Then:

```bash
git clone https://github.com/OWNER/REPO.wiki.git
cd REPO.wiki
# Copy all *.md files and the images/ folder from this package to this directory.
git add --all
git commit -m "Document Kin City v26 architecture, installation and roadmap"
git push origin master  # or the Wiki repository's actual default branch
```

Replace `OWNER/REPO` with your **actual repository**, and verify the wiki repository's branch (`git branch --show-current`) rather than assuming `master`.
