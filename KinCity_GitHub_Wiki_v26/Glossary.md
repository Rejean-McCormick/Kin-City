# Glossary

| Term | Meaning in Kin City |
| --- | --- |
| **Experience** | The Roblox experience that can contain multiple Places. |
| **Place** | A separately published Roblox world/scene with a distinct `PlaceId`. |
| **`city`** | The exterior city Place target, without large institution interiors in split mode. |
| **Institution Place** | One of eight independently generated, detailed major interiors. |
| **Place key** | Stable symbolic name such as `library` or `orgo_center`. Not a Roblox numeric ID. |
| **Place ID** | A real numeric ID created by Roblox after publishing a Place; all nine are `null` in the v26 delivery. |
| **`SPLIT_PREVIEW`** | An independent Place preview built by a targeted installer, with unpublished inter-Place travel unavailable. |
| **`LOCAL_UNIVERSE`** | Legacy single-Place setup containing city and eight interiors for local testing. |
| **`MULTI_PLACE`** | Target configuration for nine published Places and real `TeleportAsync` transitions. |
| **`WORLD_STUB`** | Active product boundary: local Roblox features work where implemented, but kOA services are not connected. |
| **Canonical plan** | Compiled data describing stable core places, anchors, doors and interactions. |
| **Build manifest** | Release-generated description of package targets and hashes, stored under `build/`. |
| **ProximityPrompt** | Roblox interaction activated near a world object, validated by server-side code. |
| **CrystalKit** | Reusable generator for the teal/opal faceted design language. |
| **PBR** | Physically based material maps that require asset import for a finished Roblox visual result. |
| **Native fallback** | Roblox-built primitive geometry used when an optional imported mesh is absent. |
| **Rojo** | Optional project-mapping tool, with layout defined by `default.project.json`. |
