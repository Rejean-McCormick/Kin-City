# Configuration Reference

The main configuration lives in `config/`. Most of it is compiled into the Luau build: editing JSON **without regenerating the installers** does not update previously installed Studio scenes.

| File | Purpose | v26 baseline |
| --- | --- | --- |
| `runtime.json` | Routing selection | `LOCAL_UNIVERSE` |
| `place_ids.json` | Real published ID for each Place key | All nine values `null` |
| `visual.json` | Build-level crystal detail profiles | `STANDARD` selected |
| `audio.json` | Original WAV asset IDs and audio enablement | `enabled: false`, IDs `null` |
| `meshes.json` | Optional imported mesh IDs/fallbacks | All 11 values `null` |
| `interior_origins.json` | Stable origin positions for historical local universe | Explicit coordinates per institution |

## Runtime routing

`LOCAL_UNIVERSE`: build exterior and eight interiors together using the **local all-in-one installer**.

`SPLIT_PREVIEW`: generated by the v26 **targeted installers** when Places have not been configured/published; scenes are separate, but inter-Place teleportation is unavailable.

`MULTI_PLACE`: requires **all nine real published Place IDs** and new release generation. Do not use a city installer in an institution Place or vice versa.

Example registry shape (shown with `null` deliberately — do not treat these as usable IDs):

```json
{
  "city": null,
  "city_hall": null,
  "ekoh_tower": null,
  "library": null,
  "campus": null,
  "justice_palace": null,
  "innovation_lab": null,
  "museum": null,
  "orgo_center": null
}
```

## Visual profiles

- `LITE`: fewer faceted crystal pieces, no new hero glass in its profile.
- `STANDARD`: default balanced architectural motifs.
- `SHOWCASE`: more detailed mandala and city ornamentation.

These are **not** a complete automatic mobile-quality system for every legacy element. Press `V` during play for the available **local** detail controls.

## Reproducibility

For changes to the code, theme or configuration, rerun `python tools/build_release.py`. Inspect `build/release-manifest.json` for hashes and artifact names. Run tests and then inspect the affected Place's output and scene tree in Studio.
