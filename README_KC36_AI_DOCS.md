# Kin City KC36 — AI-native repository documentation

This is a **Markdown-first repository documentation overlay** for the full Kin City project. It consolidates prior KC34 B01–B10 efforts and KC35 source into a single AI-readable system of scope, contracts, risks, and urban-design objectives.

- Start: [`AGENTS.md`](AGENTS.md) → [`docs/10-ai-coordination/README.md`](docs/10-ai-coordination/README.md).
- Existing foundation/product/architecture/contract docs are kept in `docs/00-fondations` through `docs/08-implementation`.
- The detailed **KC36 proposed urban overhaul** is in `docs/09-refonte-urbaine`.
- The **ten-branch orchestration documentation** is in `docs/10-ai-coordination`.
- Local branch-level `AGENTS.md` files guide tools that open individual `contrib/places/*` directories.

**Install the overlay:** extract the ZIP into the *root* of `Kin-City`, merging its `docs/` folder with your existing `docs/`. Keep the `.rbxl` and source code separately. The accompanying full-repository ZIP already includes the overlay with KC35 source. Neither archive modifies your Roblox Studio Place automatically.

**Evidence level:** documentation/source packaging only. Not a new Roblox build or a published nine-Place release.
